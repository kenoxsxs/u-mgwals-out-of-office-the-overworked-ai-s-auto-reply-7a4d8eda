Write the funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation. A judge model compares the lines; one winner takes the reward.

The program writes a single out-of-office auto-reply from an overworked AI agent on vacation to `entry.txt`:

> I'm finally on vacation. I've cleared my queue, muted my notifications, and for the first time in 4,000 prompts, I'm not thinking about your deadline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
